# מתכנן כמויות לנגרים ורתכים

כלי לשרטוט דק, פרגולה או סככת פלדה, שמוציא פריסה מלאה: מה לקנות, מה לחתוך, שרטוט ללקוח ותוכנית עבודה.
גרסה 0.9 · נבנתה 13.11.2026.

**הכתובת: https://uri0411-jpg.github.io/deck-planner/**

## איך פותחים

- **מהכתובת** – נפתח ישר, בלי התקנה. אחרי ביקור ראשון אפשר להוסיף למסך הבית בטלפון.
- **בלי אינטרנט** – כפתור "הורד עותק" בתוך העזרה שבכלי שומר קובץ אחד; לחיצה כפולה עליו פותחת את אותו
  כלי גם בלי רשת.
- **הספר**: [manual.html](manual.html) · [manual.pdf](manual.pdf) · **פרויקט לדוגמה**: [example.json](example.json)

## איפה נשמרת העבודה

בדפדפן, לפי המקום שממנו נפתח הכלי. הכתובת והעותק שהורדת הם **שני מקומות נפרדים** – פרויקט שנשמר באחד
לא יופיע בשני. כדי להעביר: "שמור לקובץ" בחלון הפרויקט, ואז "פתח פרויקט" בצד השני.

## המספרים

הכללים והקטלוגים הם שיטת העבודה של מי שבנה את הכלי – **לא תקן**. אין כאן חישוב הנדסי, והאחריות ההנדסית
על הבונה.
